One-time cloud setup

Create a free project at Supabase, then create the table with this SQL in its SQL Editor. Keep row-level security enabled.

create table if not exists public.bizbuddy_data (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.bizbuddy_data enable row level security;
create policy "Users can read their own BIZBUDDY data"
on public.bizbuddy_data for select to authenticated
using (auth.uid() = user_id);
create policy "Users can insert their own BIZBUDDY data"
on public.bizbuddy_data for insert to authenticated
with check (auth.uid() = user_id);
create policy "Users can update their own BIZBUDDY data"
on public.bizbuddy_data for update to authenticated
using (auth.uid() = user_id) with check (auth.uid() = user_id);

Security: use only the project's publishable/anon key in this page. Never paste a service-role key. Enable email confirmation in Supabase if desired. This setup has not been activated or independently security-audited for you.
